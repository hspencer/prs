PictoNet Generative Pipeline

From text input to adaptive pictogram output

Esta sección introduce las fases del pipeline de PictoNet, mostrando cómo un enunciado se transforma en un pictograma generativo, editable y culturalmente sensible.

Text Input

The user provides a short phrase or utterance.
Language defaults to Spanish but can be configured.

El punto de partida: un enunciado breve que será procesado para generar pictogramas.

Encoding, tokenisation & visual tokenisation

Processes input into semantic units using NSM primitives, identifying iconisable elements and sentence type.

Aquí se fragmenta el enunciado en tokens visuales con base en NSM.

Act of speech classification

Identifies the communicative intent (assertive, volitive, emotive, directive, hypothetical).

Se reconoce la intención comunicativa, lo cual guía el renderizado visual.

Conceptual blending

Combines action, object, and modifiers into composite visual concepts.

El blending integra metáforas y conceptos abstractos en formas visuales comprensibles.

Layout planning & composition

Determines spatial arrangement of pictographic components according to semantic weight and syntax.

Selects and layers graphical assets into a coherent pictogram with defined visual grammar.

El planificador define jerarquías visuales y disposición espacial.

Local Configuration

Applies user preferences (stroke weight, colour, density, animation tolerance).

El sistema se adapta a necesidades perceptuales o culturales de cada usuario.

Output & Metadata

Generates the final SVG with embedded metadata and prepares optional feedback signals for RLHF.

El resultado es un SVG legible y editable, con trazabilidad semántica.

Rationale

  • Communication is a basic human right
  • Individuals with Complex Communication Needs (CCN) are systematically marginalised
  • AAC systems often prioritise function over aesthetics, neglecting cultural and expressive depth
  • Design has a structural responsibility to pre-empt exclusion
  • Pictograms as generative, situated artefacts—bridging AI and design
Cognitive extension, not only tools, but infrastructures that enable agency and belonging. Cite accessibility laws (NZ, Canada, Chile, etc.). Emphasise that design itself often encodes exclusion—hence the urgency of this research.

Significance

  • Reframes accessibility as a shared condition, not a marginal issue
  • Expands expressive capacity for CCN users—abstract, affective, context-based meanings
  • Bridges AAC practice and design craft
  • Proposes participatory, federated learning models for cultural adaptation
  • Envisions a pictographic commons: an open-source evolving visual language
Highlight shift: cognitive accessibility as aesthetic and epistemological. Users move from passive recipients to co-creators of meaning. Shared commons counters fragmentation and personalisation silos.

PictoNet

The generative engine: from natural language to SVG pictograms.

  • Visual grammar grounded in semantic primitives (NSM)
  • Structured pipeline: prompt → semantic parsing → SVG generation
  • Editable, reversible, explainable outputs
  • Reinforcement Learning with Human Feedback (RLHF)
  • Open-source, Creative Commons licensed
Present PictoNet as the “core engine” of the research. Mention the lineage from PICTOS → Lectogram → PictoNet. Stress SVG as code: transparent, inspectable, modifiable.

PictoForge

The editor and trainer environment.

  • Interactive SVG editor for direct manipulation
  • Segmented re-prompting: refine parts of pictograms
  • Training interface for dataset curation
  • Supports iterative correction and validation
  • Extends design practice into everyday AAC use
PictoForge = continuation of design tools. Emphasise user agency: co-edit, correct, and refine the model. It bridges professional design practice and lived AAC use.

MediaFranca

  • PictoNet: speech-to-SVG generative core
  • PictoForge: editor and feedback interface
  • MediaFranca: federated architecture for shared intelligence

Each community contributes local adaptations → aggregated into a shared pictographic commons.

Explain the universal–local paradox in AAC. MediaFranca allows plural visual heritages without losing collective coherence. Governance: validation, contribution roles, reputation systems. Accessibility as civic infrastructure, not a service.

Methodology

  • Situated Inquiry: interviews with AAC professionals, designers, users
  • Formal Modelling: generative engine design and testing
  • Double-diamond, practice-based: making, reflecting, refining
  • Two intertwined tracks: relational & ontological
Show the Double-Diamond Double-Track figure. Stress practice-based approach: knowledge is produced through making pictograms, errors, corrections. Iterative cycles link theory and practice.
